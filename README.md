# IRUZ（居るぜ）

Windows 用のマウスジグルツールです。定期的にマウス入力をシミュレートし、OS の「最後の入力」を更新することで、Teams などの退席（離席）判定をリセットします。

キーダウン（キー入力）だと文字入力の邪魔になるため、邪魔にならないマウス移動で実装しています。

## ダウンロード・インストール

[インストーラー](https://iruz.kagayoi.com/IRUZ-win-Setup.exe)をダウンロードして実行してください。
Vector から ZIP を入手した場合は、展開して同梱の `IRUZ-win-Setup.exe` を実行してください。

## 機能

- **マウスジグル**  
  指定間隔（30 / 60 / 120 / 300 秒）で小さな往復のマウス移動を送り、OS の「最後の入力」を更新します。
- **間隔の選択**  
  ジグルを停止している間は「間隔」で秒数を変更できます。デフォルトの間隔は 60 秒です。
- **タスクトレイ常駐**  
  トレイアイコンはウィンドウを表示している間も常に出したままです。ウィンドウを最小化する、またはタイトルバーの ✕ で閉じるとタスクトレイに格納され、タスクバーからは非表示になります（どちらもジグルは動き続けます）。アプリが終了するのは「終了」ボタンかトレイメニューの「終了」を選んだときだけです。トレイアイコンのクリックまたは右クリックメニューの「表示」でウィンドウを復帰、「終了」でアプリを終了できます。アイコンのツールチップには現在の状態（ジグル中／残り時間／停止中）が出ます。
- **トレイからの全設定操作**  
  トレイアイコンの右クリックメニューだけで、メインウィンドウと同等の操作ができます。現在の状態表示、開始／停止、「間隔」「自動解除」のサブメニュー、「スタートアップに登録する」のチェックが並び、現在の選択にはチェックが付きます。間隔はウィンドウ側と同じくジグル中は変更できません。
- **自動解除タイマー**  
  「自動解除」で 1 / 2 / 3 / 4 / 5 / 6 / 8 時間後を選ぶと、その時間が経った時点でジグルを自動停止し、選択も「なし」に戻します。停止後は入力の送信が途絶えるため、通常どおりの離席判定に戻ります。ジグル中でも変更でき、変更した時点から数え直します。停止中に選んだ場合は、次に「開始」を押した時点から数えます。既定は「なし」で、選ばなければ従来どおり自分で停止するまで動き続けます。
- **カウントダウン表示**  
  自動解除を設定すると、`自動解除まで 2:59:31（18:00 に解除）` の形式で残り時間と解除予定時刻が出ます。メインウィンドウの「状態」、タスクトレイの右クリックメニュー、トレイアイコンのツールチップの3か所に表示され、1 秒ごとに更新されます。
- **起動時自動開始**  
  アプリ起動時にタスクトレイに常駐し、自動的にジグルを開始します。ウィンドウはトレイアイコンから表示できます。
- **スタートアップ登録**  
  「スタートアップに登録する」にチェックを入れると、Windows へのログイン時に IRUZ が自動起動します。チェックを外すと解除されます。

## 自動更新

起動時に更新を確認し、新しいバージョンがあればダウンロードして再起動します。更新を取得できない場合は、現在のバージョンで起動します。

## 使い方

1. アプリを起動する（自動的にジグルが開始されます）。
2. ジグルを停止したい場合は「停止」、ウィンドウだけ引っ込めたい場合は「最小化」（ジグルは動き続けます）、アプリごと終わらせたい場合は「終了」を押す。
3. 間隔を変更したい場合は、一度「停止」してから「間隔」で秒数を選び、再度「開始」を押す。
4. 決まった時間で自動的に止めたい場合は「自動解除」で時間を選ぶ（停止せずそのまま選べます）。たとえば 15:00 に「3時間後」を選ぶと 18:00 に自動停止します。
5. ウィンドウを最小化する（「最小化」ボタン、タイトルバーの ─、または ✕）とタスクトレイに収まります。トレイアイコンをクリックするか、右クリックメニューの「表示」でウィンドウを再度表示できます。
6. ウィンドウを開かずに操作したい場合は、トレイアイコンを右クリックしてメニューから直接設定してください（1〜4 と同じ操作が揃っています）。

**毎回起動しなくてよいようにするには**  
「スタートアップに登録する」にチェックを入れてください。Windows のログイン時に IRUZ が自動起動し（タスクトレイに常駐した状態で始まります）、いちいち手動で起動する必要がなくなります。解除したいときはチェックを外すだけです。

## 動作環境

- Windows 11（25H2 / ビルド 26200 を想定。それ以前の OS では未検証）
- 配布版は Native AOT でビルドされているため、.NET の別途インストールは不要です。
- 対応アーキテクチャは x64 です。

## アンインストール

「スタートアップに登録する」を解除し、トレイメニューの「終了」で IRUZ を終了してください。その後、Windows の「設定」→「アプリ」→「インストールされているアプリ」から IRUZ をアンインストールできます。
