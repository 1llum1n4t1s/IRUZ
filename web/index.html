Features

在席のフリではなく、ちゃんと「居る」と伝える。

Not pretending to be present — actually telling Windows you are.

IRUZ はマウスを微振動させて OS の「最後の入力時刻」を更新するだけのシンプルな常駐ツール。Teams や Slack の在席ステータスは、それで十分です。 IRUZ quietly nudges the mouse to refresh the OS "last input" timestamp — enough for Teams and Slack to keep you "Active".

SendInput Relative Mouse Move

SendInput による相対マウス移動

Windows API の SendInput でわずか 1px の相対移動を送信。実際のマウスは動かしません。 A 1-pixel relative move is sent via the Windows SendInput API. Your real mouse stays put.

SendInputRelative1 pxNative
30 / 60 / 120 / 300 sec

間隔をワンクリック切替

30 秒・60 秒・120 秒・300 秒の 4 段階から、用途に合わせて即切替できます。 Switch between 30, 60, 120 or 300 second intervals with a single click.

Teams & Slack Friendly

Teams の離席判定をリセット

Microsoft Teams や Slack が見ている「最後の入力時刻」を更新するので、自動的に「退席中」へ落ちません。 Refreshes the system's "last input" time that Teams & Slack watch, so you don't drop to "Away" automatically.

Auto-start at Launch

起動時に自動でジグル開始

アプリ起動と同時にジグルを開始する設定を内蔵。Windows ログイン時の自動起動と組み合わせれば完全放置 OK。 Optional auto-start on launch — combine with Windows startup to set it and forget it.

System Tray Resident

最小化でタスクトレイに常駐

最小化するとタスクバーから消えてトレイへ。作業中の画面を邪魔しません。 Minimize and IRUZ tucks itself into the system tray — out of sight, out of mind.

Mouse-only, No Keystrokes

文字入力を邪魔しない

キーストロークは一切送信しないので、編集中のドキュメントやチャットに変な文字が紛れ込みません。 No keystrokes are ever sent — your typing, chats and docs stay clean.

Native AOT, No Runtime

Native AOT 配布で .NET 不要

Native AOT で単体配布。.NET ランタイムのインストールも、起動の待ち時間もありません。 Shipped as Native AOT — no .NET runtime install, no warm-up delay.
